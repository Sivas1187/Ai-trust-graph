## Brand mark

Chosen: **B1 — a relationship with a breakpoint.** Three graph nodes in a closed
triangle of relationships; two hold, the third is interrupted by a
perpendicular control bar. Connection is not authority, and a path can be
interrupted (Act II's unresolved path; annotation b's control breakpoint).
Monochrome `currentColor`, inline SVG, no text / gradient / filter / image.

Rejected:

| Candidate | Why not |
|---|---|
| B2 · gap only | At 16–20px the gap closes visually; reads as a plain triangle. |
| B3 · hollow far node | The hollow node fills in at 16px; the extra idea costs legibility. |
| B4 · double bars | Reads as hatching or a "stop" glyph; busier than needed (round 2 only). |
| A · path + breakpoint | A thin diagonal; reads as a key, syringe or match. |
| C · bracketed relationship | Reads as code / JSON. |
| D · graph T | The barred stem reads as a dagger or cross. |
| E · previous provisional mark | A generic node cluster; illegible noise at 16px. |
