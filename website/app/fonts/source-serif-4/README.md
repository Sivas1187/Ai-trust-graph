# Source Serif 4 (self-hosted)

Display face for the visual-reset editorial typography (Cover title; later
act headings). Bundled at build time by `next/font/local` in `app/layout.tsx`
and served from this site's own origin — no remote font request at build or
run time.

| File | Contents |
|---|---|
| `SourceSerif4-Roman-latin-opsz-wght.woff2` | Upright, Latin subset, variable: optical size 8–60, weight 200–900 |
| `SourceSerif4-Italic-latin-opsz-wght.woff2` | Italic, same subset and axes (not preloaded) |
| `OFL.txt` | Licence, verbatim from `google/fonts` `ofl/sourceserif4/OFL.txt` |

- Binaries: the Google Fonts build (v14, 2025-09-11) as packaged by Fontsource
  `@fontsource-variable/source-serif-4` 5.3.0
  (`files/source-serif-4-latin-opsz-normal.woff2` and
  `files/source-serif-4-latin-opsz-italic.woff2`), renamed only. The npm
  package is not a dependency of this site.
